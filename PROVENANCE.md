# Provenance of the art

Every visual asset in `assets/` was written as code in this repository. None of it was
traced, downloaded, generated by an image model, or derived from a film, game or
other adaptation of the Odyssey.

| Asset | How it was made | Editable source |
|---|---|---|
| `characters/odysseus-vector/*.svg` (default character, all poses and episodes) | SVG primitives (circles, paths, strokes) placed by hand-written Python | `tools/make_odysseus.py` (`svg_frame`, pose table `ANIMS`) |
| `characters/odysseus-pixel.sprite` (alternative style, not updated after the vector pick) | Hand-typed pixel stamps composed by the same pose table | `tools/make_odysseus.py` (`draw_pixel`, stamps) |
| `sketches/pip.sprite`, `sketches/drift.sprite` (early discussion sketches) | Hand-typed pixel grids | `tools/make_sprites.py` |
| `sketches/placeholder.sprite` (neutral pebble) | Rasterised ellipses, squash-and-stretch only | `tools/make_sprites.py` |
| `icon/AppIcon.svg`, `AppIcon.icns` (app icon) | The vector walk frame above placed on a hand-written SVG scene (sky, sun, sea, edge trail) | `tools/make_icon.py` |
| `previews/*.png`, `../character-sheet/*` | Rendered from the sources above | `tools/make_character_sheet.py`, `tools/svg2png.swift` |

Story sources: Homer's *Odyssey* (public domain worldwide). Each episode cites the book
it comes from in `Sources/Episodes.swift`. No modern translation text is reproduced.

## Who made it, and what that means for ownership

- The drawings were authored as code by an AI coding agent (Claude, in a Claude Code
  session on the owner's Mac) at the owner's direction, with the owner choosing the
  concept (Odysseus), the style (clean vector) and giving feedback.
- No company account, company tool or company asset was used for the art itself.
  The Claude Code session's account (personal vs company) is for the owner to confirm;
  if it was a company account, check the company's IP policy before selling.
- Copyright in material produced mainly by an AI system can be weak or absent in some
  countries (for example the U.S. Copyright Office requires meaningful human authorship).
  Before selling character packs, have a human (the owner or a commissioned artist)
  make substantial creative edits or redraw the final art, and keep these files and
  the design-meeting notes as a record. This is not legal advice.
